第 3 章 イーサネットと MAC アドレス　3-1

一番外側の封筒に書かれた宛先の番号

このページでわかること

同じ配線でつながる機械どうしがデータをやり取りするときは、送りたいデータに宛先や送信元の番号を書き加えた、ひとまとまりの単位にして送っている。このページでは、その番号の正体と、単位の中の並び順を確認する。

このページの目次

かけあい

1-4 でちらっと MAC アドレスとかフレームって言葉が出てきましたけど、結局何なんですか?

同じ配線でつながる機械どうしが、お互いの宛先を確認するための仕組みです。この配線の共通ルールを、イーサネットと呼びます。

IP アドレスも宛先みたいなものですよね? 何が違うんですか?

範囲が違います。MAC アドレスは同じ配線の中だけで使う番号で、IP アドレスはネットワークをまたいで使う番号です。

じゃあ同じ配線の中では、IP アドレスは使わないんですか?

使いますが、それだけでは足りません。実際に送るときは、パケットに宛先などの情報を書き足した、別の単位にして送ります。

その単位にも名前があるんですか?

あります。宛先 MAC アドレス、送信元 MAC アドレス、種別、データ、誤り検出の順に並んだ単位を、フレームと呼びます。

宛先が先に来て、送信元がその後なんですね。データのところには何が入るんですか?

1-4 で見たパケットが、まるごと入ります。封筒の中に、もう一つ封筒が入っているような感じです。

じゃあ最後の誤り検出は何のためにあるんですか?

送っている途中で信号が乱れて、中身が変わっていないかを確かめるためのものです。

MAC アドレスって、自分で決めるものなんですか?

いいえ、多くは機械のネットワーク部品にあらかじめ付いています。同じ配線の中で機械を区別するための番号です。

でも、相手の MAC アドレスなんて普段意識したことないです。どうやって知るんですか?

IP アドレスから、対応する MAC アドレスを調べる仕組みがあり、これをARPと呼びます。詳しい手順は第 7 章で扱います。

MAC アドレスって、機械を買い替えない限りずっと同じなんですか?

基本的にはそうです。同じ配線の中で機械を区別する番号なので、置き場所が変わっても番号自体は変わらないのが普通です。

IP アドレスは変わることがあるって聞いたことあるんですけど、MAC アドレスは違うんですね。

そうです。IP アドレスはつながるネットワークによって変わることがありますが、MAC アドレスは機械そのものに結びついた番号です。

誤り検出って、具体的にはどうやって確かめているんですか?

送るデータをもとに計算した数字を一緒に送っておき、受け取った側で同じ計算をして、数字が一致するかどうかを確認します。

じゃあ今日のところは、フレームの並び方と MAC アドレスの役割を覚えておけばいいですか?

はい、それで十分です。次は、このフレームを複数の機械がいる中でどうやって届けるかを見ましょう。

まとめ

  • 同じ配線でつながる機械どうしがデータをやり取りするときの共通の約束事を、イーサネットと呼ぶ。
  • 実際にやり取りする単位をフレームと呼び、宛先 MAC アドレス・送信元 MAC アドレス・種別・データ・誤り検出の順に並ぶ。
  • MAC アドレスは、同じ配線の中で機械を区別するための番号で、ネットワークをまたいで使う IP アドレスとは役割が違う。
  • フレームのデータの部分には、パケットがそのまま入る。
  • MAC アドレスは機械そのものに結びついた番号で、置き場所が変わっても基本的には変わらない。ネットワークによって変わることがある IP アドレスとは、この点でも性質が違う。
  • 相手の MAC アドレスを調べる仕組み(ARP)は第 7 章で扱う。

しくみの話

宛先MACアドレス → 送信元MACアドレス → 種別 → データ（パケット） → 誤り検出

イーサネットは、有線でつないだ機械どうしが同じ配線の中でデータをやり取りするときの共通の約束事である。実際にやり取りする単位がフレームで、宛先 MAC アドレス・送信元 MAC アドレス・種別・データ・誤り検出という順で情報が並ぶ(#71 p.14、#4 p.114)。データの部分には、1-4 で見たパケットがそのまま入る。MAC アドレスは機械のネットワーク部品にあらかじめ付いている番号で、同じ配線の中だけで機械を区別するために使われ、IP アドレスのようにネットワークをまたいでは使われない(#4 p.116)。誤り検出は、送信中に信号が乱れて中身が変わっていないかを確かめるためのもので、送るデータをもとに計算した数字を一緒に送り、受け取った側で同じ計算をして一致を確かめる仕組みである。MAC アドレスは機械のネットワーク部品に結びついているため、機械を別の配線につなぎ替えても、番号そのものは基本的に変わらない。
