第 25 章 VPC をつなぐ — ピアリング・ハブ・ハイブリッド　25-2

たくさんの VPC を、まとめてつなぐ

このページでわかること

VPC の数が増えると、前のページで見た 1 対 1 でつなぐやり方だけでは大変になる。まとめてつなぐ方法と、1 つの VPC を複数のチームで使う方法という、2 つの別々の答えがある。このページでは、その両方を確認する。

このページの目次

かけあい

前のページで、VPC の数が増えたら大変になるって言ってましたけど、具体的にどれくらい大変になるんですか?

数字で見てみましょう。VPC が 100 個あって、全部を直接 VPC ピアリングでつなごうとすると、必要な接続は 4,950 個にもなります。

そんなに! 1 つの VPC が持てる接続の数にも、限りがありそうですね。

そのとおりです。1 つの VPC が持てる VPC ピアリング接続には上限があります。

じゃあ、VPC がたくさんある場合は、どうすればいいんですか?

たくさんの VPC を 1 か所に集めてつなぐ仕組みを使います。AWS ではこれをTransit Gatewayと呼びます。

1 か所に集めるって、具体的にはどういうことですか?

Transit Gateway が持つ経路の設定にしたがって、つながっている VPC 同士の通信を中継します。VPC はそれぞれ、Transit Gateway とだけつながればよくなります。

なるほど、1 対 1 でつながなくてよくなるんですね。ところで、AWS の資料でたまに見かける「シェアード VPC」って、これとは別の仕組みですか?

別の仕組みで、共有 VPCと呼びます。1 つの VPC を、複数のチームやアカウントで分担して使えるようにする仕組みです。

つなぐ仕組みじゃなくて、使う仕組みってことですか?

そうです。Transit Gateway は VPC を「つなぐ数」を減らし、共有 VPC は VPC を「作る数」を減らします。

作る数を減らすって、具体的にどういうことですか?

たとえば 10 個のアプリをそれぞれ別のアカウントで動かしていても、似た用途ごとに 1 つの VPC を共有すれば、VPC の数自体を 2 個に減らせます。

10 個から 2 個に! それぞれのアプリを、どうやって分けて管理するんですか?

共有 VPC の中でも、サブネットを分けて割り当てます。第 24 章 24-3 で見た NACL を使えば、サブネットごとに通信を区切れます。

Transit Gateway と共有 VPC、両方一緒に使うこともあるんですか?

あります。共有 VPC 同士を Transit Gateway でつなぐ、という組み合わせ方もよくあります。次のページでは、社内のネットワークとつなぐ方法を見ていきましょう。

まとめ

  • VPC が 100 個あって全部を直接 VPC ピアリングでつなごうとすると、必要な接続は 4,950 個にもなり、1 つの VPC が持てる接続数にも上限がある。
  • Transit Gateway は、たくさんの VPC や社内ネットワークを 1 か所に集めてつなぎ、経路の設定にしたがって通信を中継する仕組みである。
  • Transit Gateway を使うと、VPC はそれぞれ Transit Gateway とだけつながればよくなる。
  • 共有 VPC は、1 つの VPC を複数のチームやアカウントで分担して使えるようにする仕組みである。
  • Transit Gateway は VPC を「つなぐ数」を減らし、共有 VPC は VPC を「作る数」を減らす、別々の課題への答えである。
  • 10 個のアプリをそれぞれ別のアカウントで動かしていても、用途ごとに 1 つの VPC を共有すれば、VPC の数を 2 個に減らせる。

しくみの話

VPC の数が増えるほど、直接 VPC ピアリングでつなぐ組み合わせは急激に増える。100 個の VPC を全部 VPC ピアリングでつなごうとすると、必要な接続は 4,950 個にもなり、1 つの VPC が持てる VPC ピアリング接続にも上限がある(#26)。Transit Gateway は、たくさんの VPC や社内ネットワークを 1 か所に集めてつなぎ、そこが持つ経路の設定にしたがって、VPC 同士の通信を中継する仕組みである(#23、#26)。VPC はそれぞれ Transit Gateway とだけつながればよく、接続の組み合わせを管理する手間が減る。共有 VPC は、これとは別の課題への答えで、1 つの VPC を複数のチームやアカウントで分担して使えるようにする仕組みである(#26)。たとえば 10 個のアプリケーションをそれぞれ別のアカウントで動かしていても、用途ごとに 1 つの VPC を共有すれば、VPC の数自体を 2 個に減らせる(#26)。Transit Gateway は VPC を「つなぐ数」を減らし、共有 VPC は VPC を「作る数」を減らす、という違いがある。
