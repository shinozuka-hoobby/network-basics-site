第 7 章

ARP と同一ネットワーク内の通信

この章で分かること

  • 宛先の IP アドレスと自分のサブネットマスクを使って、相手が自分と同じサブネットにいるかどうかを判定する仕組みを説明できる。
  • IP アドレスから対応する MAC アドレスを調べる仕組みである ARP が、ブロードキャストで尋ねて本人が答える動作であることを説明できる。
  • 別のサブネット宛ての通信は、デフォルトゲートウェイという機械にいったん託されることを説明できる。
  • 宛先 MAC アドレス(次に渡す隣の機器)と宛先 IP アドレス(最終的な相手)が、1 つのパケットが送られる中でどう変わり、どう変わらないかを、送信の流れとして追える。

中心図

送信元ホストは、宛先 IP アドレスと自分のサブネットマスクから、宛先が同じサブネットにいるかを判定する。同じサブネットなら ARP で宛先本人の MAC アドレスを調べて直接送り、宛先 MAC アドレスと宛先 IP アドレスは両方とも本人のままになる。別のサブネットなら ARP でデフォルトゲートウェイの MAC アドレスを調べて託し、宛先 MAC アドレスはデフォルトゲートウェイのものに変わるが、宛先 IP アドレスは最終的な相手のまま変わらない。そこから先、デフォルトゲートウェイがどう転送するかは第 8 章で扱う。
