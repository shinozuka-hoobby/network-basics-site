ネットワークのしくみ — Web エンジニアのための基礎講座

このサイトについて

HTTP や API、クラウドの利用経験はあるけれど、L2〜L4・ルーティング・DNS・TLS・CDN・VPC 設計の理解が断片的な Web エンジニア（実務 2〜5 年目）を対象に、「ブラウザで URL を開くと HTML が返ってくる」という前提だけから 積み上げて説明する全 31 章の講座です。m01 から番号順に読み進めることを想定しており、 各章は 3〜5 ページに分かれ、1 ページは 10 分ほどで読めます。読了したページとクイズの正解は、 この端末のブラウザ内（localStorage）にのみ記録され、どこにも送信されません。

学習マップ

学習マップを読み込んでいます…

同じ Apple ID の iPhone と Mac なら、コピーしたリンクをもう一方の端末で開くと、読了とクイズ正解の記録がまとめて取り込まれます。 このサイトはページの URL の末尾に進捗を付けているので、Safari の Handoff（Dock や App スイッチャーに出る Safari のアイコン）や iCloud のタブから開いた場合も自動で取り込まれます。 取り込みは足し合わせで、記録が消えることはありません。「学習記録をリセット」は端末ごとに行います。

参考文献の一覧は こちら。進捗（読了ページ・クイズ正解）はこの端末のブラウザ内にのみ保存され、別の端末に持ち運ぶときは、上の「進捗リンクをコピー」を使います。
