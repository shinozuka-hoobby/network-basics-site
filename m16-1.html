第 16 章 DNS の仕組み　16-1

名前解決は誰に聞き、誰が答えを持っているか

このページでわかること

名前解決は、1 台の機械だけで完結する処理ではない。代わりに問い合わせに行く側と、答えを持っている側は、別の機械が担当している。このページでは、この役割分担を確認する。

このページの目次

かけあい

DNS って、第 1 章とか第 4 章とか、いろんなところで名前だけ出てきましたけど、結局何のことだったんでしたっけ?

ドメイン名を IP アドレスに変換する仕組み全体のことを、DNS と呼びます。これまで見てきた場面は、みんなこの仕組みの一部だったんです。

変換してるのは、1 台の機械なんですか?

いいえ、役割が分かれています。ブラウザの代わりに答えを探しに行く機械がいて、これをDNS リゾルバと呼びます。

そのリゾルバは、誰に聞きに行くんですか?

そのドメイン名について、最終的な答えを持っている機械に聞きに行きます。これを権威サーバと呼びます。

第 4 章で、DHCP が「名前を IP アドレスに変える仕組みを担当するサーバのアドレス」を配るって話がありましたけど、あれがリゾルバのアドレスだったんですか?

そのとおりです。第 1 章 1-3 で見た「ISP が用意した別のサーバか、公開されている DNS サーバ」が、まさにリゾルバの居場所です。

ブラウザが権威サーバに直接聞きに行けばいい気もするんですけど、なんでリゾルバを挟むんですか?

権威サーバの居場所は、聞く名前ごとに違います。リゾルバが代わりに探しに行ってくれるので、ブラウザ側は迷わずに済みます。

なるほど、探す手間をリゾルバが引き受けてくれてるんですね。

そうです。見つけた答えは、リゾルバがブラウザに返します。

これって、ページを開くたびに毎回裏側で動いてるんですか?

そうです。利用者が意識することはほとんどありませんが、ページを開くたびにこの一連のやり取りが行われています。

DNS リゾルバって、みんな同じものを使ってるんですか?

いいえ。契約している回線事業者が用意したものや、誰でも使える公開のものなど、いくつか選択肢があります。

権威サーバの方は、答えを渡したら終わりですか?

権威サーバの役目はそこまでです。ただ、リゾルバの側には続きがあって、この章の後半で詳しく見ていきます。

楽しみです。権威サーバは、ドメインごとに違う機械なんですか?

そうです。ドメインごとに、その名前を管理している権威サーバがいます。

じゃあ、リゾルバが権威サーバを見つけるのって、簡単なことじゃなさそうですね。

そのとおりです。今日のところは、代わりに聞きに行くリゾルバと、答えを持っている権威サーバという役割分担を覚えておいてください。

代わりに聞きに行く側と、答えを持ってる側で、役割がはっきり分かれてるんですね。

そうです。次のページでは、リゾルバがどうやって権威サーバにたどり着くかを見ていきましょう。

まとめ

  • DNS は、ドメイン名を IP アドレスに変換する仕組み全体を指す呼び名である。
  • ブラウザの代わりに答えを探しに行く役目を DNS リゾルバ、あるドメイン名について最終的な答えを持っている機械を権威サーバと呼ぶ。
  • 権威サーバの居場所は名前ごとに異なるため、DNS リゾルバが代わりに探しに行き、見つけた答えをブラウザに返す。
  • DHCP が配る「名前を IP アドレスに変える仕組みを担当するサーバのアドレス」や、ISP が用意したサーバ・公開されている DNS サーバは、いずれも DNS リゾルバの居場所を指している。
  • この一連のやり取りはページを開くたびに裏側で自動的に行われており、利用者が直接操作する場面はほとんど無い。

しくみの話

DNS は、ドメイン名を IP アドレスに変換する仕組み全体の呼び名であり、1 台の機械だけでは成り立たず、複数の機械が役割を分担している(#52)。ブラウザの代わりに答えを探しに行く機械を DNS リゾルバ、あるドメイン名について最終的な答えを持っている機械を権威サーバと呼ぶ(#52、#71 p.22〜23、#24)。権威サーバの居場所は問い合わせる名前ごとに異なるため、ブラウザは直接権威サーバを探さず、DNS リゾルバに探索を任せる。DNS リゾルバが見つけた答えは、ブラウザに返される。この一連のやり取りは、ページを開くたびに裏側で自動的に行われており、利用者が直接操作する場面はほとんど無い(#52)。DNS リゾルバは 1 種類に決まっているわけではなく、契約している回線事業者が用意したものや、誰でも使える公開のものなど、いくつかの選択肢がある。第 4 章で見た、DHCP が配る「名前を IP アドレスに変える仕組みを担当するサーバのアドレス」は DNS リゾルバの居場所を示す情報であり、第 1 章 1-3 の「ISP が用意した別のサーバか、公開されている DNS サーバ」も同じ DNS リゾルバのことを指している。

試してみよう

nslookup example.com

見方: 答えの前に「Non-authoritative answer」(権威ある答えではない、という意味の注記)という一行が出る。答えを返したのは、答えを持っている権威サーバそのものではなく、代わりに探しに行った DNS リゾルバだという手がかりとして見てほしい。

command not found などで動かなければ、読むだけで進んでよい。
