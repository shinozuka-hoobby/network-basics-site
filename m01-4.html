第 1 章 パケットの旅　1-4

層に分ける理由と封筒の重なり

このページでわかること

通信の仕組みは、役割ごとの層(レイヤ)に分けて設計されている。1 つのデータは、送信される途中で何重にも包まれて送られていく。このページでは、層に分ける理由と、データが包まれていく様子を確認する。

このページの目次

かけあい

そういえば、IP アドレスだけじゃなくて、ポート番号とか URL とか、宛先っぽいものがいくつも出てきますよね。何でそんなに種類があるんですか? 1 つに統一すればいいのに。

それぞれ担当する範囲が違うからです。通信の仕組みは、役割ごとの層(レイヤ)に分けて設計されています。

層って、上下に積み重なってるってことですか?

はい。実務でよく使われる整理が、TCP/IP モデルと呼ばれる 4 層の整理です。教科書だと、OSI 参照モデルという 7 層の整理も出てきますが、今日は名前と大まかな対応だけ知っておけば十分です。

2 つも覚えるんですか…

対応関係だけで大丈夫です。TCP/IP モデルの一番下の層が OSI 参照モデルの下 2 つの層に、真ん中がネットワーク層とトランスポート層に、一番上がそれより上の層をまとめたものに、おおよそ対応します。

じゃあ、さっき出てきた IP アドレスやポート番号は、どの層の話なんですか?

IP アドレスは真ん中の層の宛先で、ネットワークをまたいで届けるために使います。ポート番号も同じ層の少し上で、端末の中のどのアプリケーションに渡すかを決めます。

IP とかTCPって、プロトコルって呼ばれたりしますよね? プロトコルって何なんですか?

通信のやり方を決めた共通の取り決めのことです。HTTP や TCP、IP は、それぞれの層で使われるプロトコルです。

もう 1 つ、宛先みたいなものってあるんですか?

あります。一番下の層では、同じネットワーク内で次に渡す隣の機器を指すMAC アドレスを使います。

じゃあ実際に HTTP リクエストを送るとき、この層は具体的に何をしてるんですか?

層ごとに、データの前にヘッダ(header)という情報を付け足していきます。まず TCP の層で TCP ヘッダが付き、次に IP の層で IP ヘッダが付き、最後に一番下の、有線 LAN の配線とデータの形式を決めた約束事であるイーサネットの層でヘッダが付きます。それぞれの中身は、専用の章(第 13 章、第 3 章)で説明します。

ヘッダが「前に付く」って、データを包むみたいなことですか?

近いです。手紙を封筒に入れて、さらに別の封筒に入れるようなイメージで簡略化できます。正式にはこの処理をカプセル化(encapsulation)と呼びます。

じゃあ、その封筒に入ったかたまりにも名前があるんですか?

データは大きな 1 つの塊としてではなく、小分けにしたかたまりとして送られます。この、小分けにされたひとかたまりをパケット(packet)と呼びます。

そのうち、一番外側までヘッダが揃った、MAC アドレス宛てのかたまりをフレームと呼びます。

途中のルータは、この封筒を全部開けて中を見たりするんですか?

見ません。ルータは自分の層のヘッダ、つまり IP ヘッダの宛先だけを見て次に転送します。中の TCP ヘッダや HTTP の中身までは基本的に見ません。

層ごとに見る場所を決めてるから、そんなことができるんですね。無線を有線に変えても、上の方は変えなくていいってことですか?

その通りです。層を分けているおかげで、下の層(回線の種類)を変えても、上の層(TCP や HTTP)を作り直す必要がありません。これが層に分ける一番の理由です。

まとめ

  • 通信の仕組みは役割ごとの層(レイヤ)に分けて設計されており、実務では TCP/IP モデル(4 層)、教科書では OSI 参照モデル(7 層)がよく使われる。
  • IP アドレス・ポート番号・MAC アドレスは、それぞれ別の層の宛先である。
  • データは層を下りるごとにヘッダが付け加えられ(カプセル化)、途中のルータは自分の層のヘッダだけを見て転送する。
  • 層を分けているおかげで、ある層(回線の種類など)を変えても、他の層(TCP や HTTP など)を作り直す必要がない。

しくみの話

京都大学の資料が示す対応表では、OSI 参照モデルの物理層・データリンク層が TCP/IP モデルの一番下の層に、ネットワーク層が真ん中の層に、トランスポート層はそのまま、セッション層以上が一番上の層にまとめられている(#73)。ヘッダは宛先などの情報を持ち、送信側は上位層のデータに下位層のヘッダを順に付け加える(カプセル化)。受信側はその逆に、外側のヘッダから順に取り除いていく(#12)。この対応関係を丸暗記する必要はなく、「今どの層の話をしているか」を都度確認する習慣が、後のページの理解を助ける。
