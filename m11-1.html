第 11 章 IPv6　11-1

新しい形式の IP アドレスは、8 つの組でできている

このページでわかること

今使われている IP アドレスの数には限りがあり、機械の増える速さに対して足りなくなってきている。そこで、今よりもはるかに多くの数を用意できる、新しい形式の IP アドレスが使われ始めている。このページでは、その新しい形式がどんな数字でできていて、どう書くのかを確認する。

このページの目次

かけあい

第 5 章で、IP アドレスは全部で約 43 億通りって聞いたんですけど、これっていつか足りなくなったりしないんですか?

実は、もう足りなくなってきています。世界中でネットにつながる機械がどんどん増えているので、新しい形式の IP アドレスが作られました。

その新しい形式は、どれくらいの数を用意できるんですか?

0 と 1 が 128 個並ぶ数字になっていて、2 の 128 乗という、桁違いに多い数を用意できます。この新しい形式を IPv6 と呼びます。

128 個も並んだら、書くのが大変そうですね。

そのままだと大変なので、16 進数(0 から 9 の数字のあとに a から f までの文字も使って数を表す書き方)にして、16 個ずつ 8 つの組に分け、コロンで区切って書きます。

第 5 章では、8 個のビットで 1 つの組が 0〜255 の範囲でしたよね。新しい形式の 1 つの組は、どれくらいの範囲になるんですか?

新しい形式は 16 個のビットで 1 つの組を表すので、0 から ffff(10 進数で 65535)までの範囲になります。IPv4 より広い範囲を、16 進数で短く書き表しています。

具体的には、どんな見た目になるんですか?

たとえば 2001:0db8:beef:cafe:0000:0000:0000:1234 のように書きます。8 つの組が、コロンで区切られているのが分かりますか?

0000 が 3 つも並んでますけど、これも省略できたりするんですか?

できます。まず各組の先頭の 0 は省略できるので 2001:db8:beef:cafe:0:0:0:1234 と書けます。さらに、0 だけが連続する部分は「::」でまとめて省略できるので 2001:db8:beef:cafe::1234 とも書けます。

「::」って、何度でも使っていいんですか?

決まりごととして、1 つのアドレスにつき「::」で省略できるのは 1 回までです。省略できる場所が複数あっても、まとめて省略できるのは 1 か所だけです。

第 5 章の CIDR 表記みたいに、範囲を表す書き方もあるんですか?

あります。同じように「/」に続く数字で範囲を表します。たとえば 2001:db8::/32 のように書きます。

新しい形式に対応してるサービスって、実際どれくらいあるんですか?

まだ半分にも届いていません。ある調査では、2025 年のインターネット全体の通信のうち新しい形式を使った通信の割合は平均で 23.9% ほどで、前の年より 25.2% 増えたそうです。少しずつですが、確実に増えてきています。

じゃあ、しばらくは両方の形式が使われ続けるんですね。

そのとおりです。次のページでは、この新しい形式ならではの仕組みも見ていきましょう。

まとめ

  • 今の IP アドレスの形式(IPv4)では約 43 億通りしか用意できず、機械の増加に対して足りなくなってきている。
  • 新しい形式の IP アドレス(IPv6)は、0 と 1 が 128 個並ぶ数字で、2 の 128 乗という桁違いに多い数を用意できる。
  • IPv6 は 16 個ずつ 8 つの組に分けて 16 進数にし、コロンで区切って書く。各組の先頭の 0 や、0 だけが連続する部分は省略できる(「::」は 1 回まで)。
  • IPv4 の CIDR 表記と同じように、「/」に続く数字でアドレスの範囲を表すこともでき、新しい形式の普及はまだ一部にとどまっている。

しくみの話

今の IP アドレスの形式(IPv4)は 0 と 1 が 32 個並ぶ数字で、用意できる数は約 43 億通りに限られる。世界中でネットにつながる機械が増え、この数では足りなくなってきたため、0 と 1 が 128 個並ぶ新しい形式の IP アドレス、IPv6 が使われ始めた(#67)。IPv6 は 2 の 128 乗という、桁違いに多い数を用意できる。128 個のビットは、そのままでは読み書きしにくいため、16 個ずつ 8 つの組に分け、それぞれを 16 進数にしてコロン(:)で区切って書く(例: 2001:0db8:beef:cafe:0000:0000:0000:1234、#4)。各組の先頭の 0 は省略でき、0 だけが連続する部分はさらに「::」でまとめて 1 回だけ省略できる(例: 2001:db8:beef:cafe::1234、#4)。IPv4 の CIDR 表記と同じように、「/」に続く数字でアドレスの範囲を表すこともできる(例: 2001:db8::/32)。新しい形式の普及はまだ一部にとどまっており、2025 年時点でインターネット全体の通信のうち新しい形式が占める割合は平均 23.9% ほどである(#69)。

試してみよう

host example.com

見方: 「has address」の行に加えて「has IPv6 address」という行が表示されることがある。これは、そのドメインが新しい形式の IP アドレスでもアクセスできることを示している。

「has IPv6 address」が出ないこともある。まだ対応していないか、環境によって見えないだけなので、読むだけで進んでよい。
