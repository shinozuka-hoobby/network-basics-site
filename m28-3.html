第 28 章 パケットキャプチャ — tcpdump と Wireshark　28-3

保存して後で見る

このページでわかること

記録した内容は、その場で見るだけでなく、ファイルに保存しておける。保存したファイルを読み込み直す操作には、特別な権限が要らない。このページでは、保存と読み込み直しの方法を確認する。

このページの目次

かけあい

保存する場所やファイル名は、好きに決めていいんですか?

はい。-w の後ろに書いた場所に、その名前で保存されます。拡張子を .pcap にしておかなくても、tcpdump 自身が中身を見て形式を判別できます。

保存してる間、ちゃんと記録できてるか不安になりそうです。

-v を付けておくと、1 秒ごとに記録した件数を知らせてくれます。進み具合を確認しながら保存できます。

保存したファイルは、あとからどうやって見るんですか?

-r オプションで読み込み直せます。この保存形式を pcap ファイルと呼びます。

読み込み直すときも sudo が要るんですか?

いいえ。保存済みのファイルを読み込むだけなら、ネットワークインターフェースから直接読み取る操作ではないので、特別な権限は要りません。

読み込んだファイルに対して、28-2 で見た port のような条件を付けることもできますか?

できます。-r で読み込むときも、同じキャプチャフィルタの条件を続けて書けます。広く保存しておいて、見るときに絞り込む、という使い方もできます。

じゃあ、記録だけ手元でしておいて、あとでゆっくり見返せるんですね。

そうです。試しに、20 個記録してファイルに保存し、そのファイルを読み込み直してみましょう。

1 行目は sudo が要って、2 行目は要らない、ということですね。

そのとおりです。1 行目はライブでインターフェースから読み取るので sudo が要りますが、2 行目は保存済みのファイルを読むだけなので要りません。

保存したファイルは、他のツールでも開けるんですか?

開けます。pcap ファイルは Wireshark でも読み込めます。記録する側と読み解く側で同じ形式を使っているので、別のツールに移して見返すこともできます。

そういえば、個人開発で、tcpdump を試しに動かしてファイルに保存したまま忘れてて、気づいたら数ギガバイトになってたことがあります。

-c で個数を指定していないと、Ctrl+C で止めるまで記録し続けます。ファイルに保存する -w と組み合わせていると、その分だけファイルが大きくなり続けます。

じゃあ、次からは -c を付けて記録すれば、同じ失敗はしませんね。

そのとおりです。個数を決めておけば、記録が際限なく続くことはありません。

保存しておけば、あとで何度でも見返せるのは便利ですね。障害調査のときとかに使えそうです。

そのとおりです。その場で見きれなかった通信も、あとでじっくり確認できます。

Wireshark ならではの見方があるってことですか?

はい。記録済みの内容から、あとで条件を変えて絞り込み直せます。次のページで、その絞り込み方を見ていきましょう。

まとめ

  • 個数(-c)を指定せずに tcpdump を実行すると、Ctrl+C で止めるまで記録し続ける。-w と組み合わせたまま止め忘れると、ファイルが大きくなり続ける。
  • -w で記録した内容をファイルに保存できる。この保存形式を pcap ファイルと呼ぶ。
  • 保存済みの pcap ファイルは、-r オプションで読み込み直せる。読み込むだけなら特別な権限は要らない。
  • pcap ファイルは tcpdump でも Wireshark でも開ける。

しくみの話

pcap ファイルは、記録した通信の内容を、あとで見返せるように保存しておくファイルの形式である。tcpdump では -w <ファイル名> で保存できる(#107)。個数(-c)を指定せずに記録を続けると、Ctrl+C で止めるまで記録され続けるため、-w と組み合わせたまま止め忘れると、ファイルは大きくなり続ける(#107)。保存した pcap ファイルは、-r <ファイル名> で読み込み直せる。保存済みのファイルを読み込む操作は、ネットワークインターフェースから直接読み取る操作ではないため、特別な権限は要らない(#107)。-r で読み込むときにも、28-2 で見たキャプチャフィルタの条件式をそのまま続けて書け、実際に処理される対象は条件に一致するパケットだけになる(#107)。-v を付けて -w と組み合わせると、標準エラー出力に 1 秒ごとの記録件数が表示される(#107)。pcap ファイルは、他の記録・解析ツールとの間でも読み書きできる共通の形式であり、tcpdump が保存したファイルを Wireshark で開くこともできる(#107、#113)。

試してみよう

sudo tcpdump -i en0 -n -c 20 -w ~/capture.pcap
tcpdump -n -r ~/capture.pcap

見方: 1 行目で 20 個のパケットを ~/capture.pcap というファイルに保存し、2 行目でそのファイルを読み込み直します。2 行目は sudo を付けていませんが、保存済みのファイルを読むだけなので、それで実行できます。

2 行目は、1 行目の保存が終わってから実行する。command not found などで動かなければ、読むだけで進んでよい。
