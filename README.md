# ネットワークのしくみ — Web エンジニアのための基礎講座

公開ページ: https://shinozuka-hoobby.github.io/network-basics-site/

## このサイトについて

ネットワークの基礎を学び直したい Web エンジニア向けの学習サイト。TCP/IP の階層、IP・サブネット、ルーティング、DNS、TLS、HTTP/2・HTTP/3、CDN、クラウドの VPC 設計、障害調査までを 31 章・137 ページで扱う。

各ページは「ひよこちゃん（学ぶ側）とふくろう先生（教える側）のかけあい → まとめ → しくみの話 → 試してみよう → 参考文献 → クイズ」という構成で書かれている。ネットワークに詳しくない状態から読み始められるように、専門用語は初出のページで説明し、以降は用語集からたどれるようにしている。

## 使い方

左のサイドバーの目次か、上部の検索から読みたい章・ページを選ぶ。第 1 章から順に読み進める構成だが、必要な章だけを読んでも理解できるように書いている。

読了したページとクイズの正解・不正解は、閲覧しているブラウザの localStorage にのみ保存される。外部のサーバーには送信されない。別のブラウザや別の端末で開いた場合、記録は引き継がれない。
