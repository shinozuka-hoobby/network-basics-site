第 11 章 IPv6　11-2

ARP の役目を、新しい仕組みが引き継ぐ

このページでわかること

同じネットワークの中にいる相手と実際に通信するには、IP アドレスだけでなく相手の MAC アドレスも必要になる。新しい形式の IP アドレスでは、この役目を ARP とは別の仕組みが引き継いでいる。このページでは、その仕組みがどう働くのかを確認する。

このページの目次

かけあい

第 7 章 7-2 で見た ARP、新しい形式の IP アドレスでも同じように使うんですか?

同じネットワーク内の相手の MAC アドレスを調べる必要があるのは同じですが、ARP そのものは使いません。新しい形式の IP アドレスでは、別の仕組みが使われます。

え、じゃあどうやって調べるんですか?

近隣探索(ND)という仕組みが、同じ役目を引き継いでいます。IP アドレスから対応する MAC アドレスを調べるという目的は、ARP とまったく同じです。

ARP とは別の、新しい専用の仕組みが用意されたんですか?

専用の仕組みではなく、第 6 章で見た ICMP の IPv6 版(ICMPv6 と呼びます)の一部として組み込まれています。新しい形式のアドレスに合わせて、すでにある ICMP の仕組みの中に入れる形が選ばれました。

ICMP の一部だったんですね。尋ね方も ARP と同じなんですか?

いいえ、違います。ARP は第 7 章 7-2 で見たとおり、同じネットワークの全員に一斉に呼びかけるブロードキャストを使いましたが、近隣探索はブロードキャストを使いません。

じゃあ、どうやって呼びかけるんですか?

マルチキャストと呼ばれる、宛先を絞ったグループ全員にだけ届く呼びかけ方を使います。動画の配信などにも使われる仕組みで、近隣探索でもこの呼びかけ方が使われています。

答える側は、ARP と同じように本人だけが返事をするんですか?

はい、そこは ARP と同じです。呼びかけられた中で、その IP アドレスを持つ機械だけが返事をします。全員に返事をさせないことで、無駄なやり取りを減らせます。

第 7 章 7-1 で見たデフォルトゲートウェイの MAC アドレスを調べたいときも、近隣探索が使われるんですか?

使われます。近隣探索は、相手が最終的な宛先かデフォルトゲートウェイかを区別せず、同じネットワークにいる機械であれば同じように働きます。

ちなみに、第 7 章 7-2 の ARP キャッシュみたいに、調べた対応をしばらく覚えておく仕組みもあるんですか?

あります。近隣探索でも、一度調べた対応はしばらく覚えておく仕組みが用意されています。ARP キャッシュと同じような考え方です。

じゃあ、違うのは呼びかけ方と、仕組みの位置づけくらいなんですね。

そのとおりです。ARP は独立した専用の仕組みで、近隣探索は既存の仕組みに相乗りしている、という違いです。役目は同じでも、作り方が違います。

なるほど、役目は同じでも仕組みの作り方が違うんですね。

そのとおりです。次のページでは、この新しい形式の IP アドレス自体が、どうやって機械に割り当てられるのかを見ていきましょう。

まとめ

  • 同じネットワーク内の相手の MAC アドレスを調べる役目は、新しい形式の IP アドレスでも必要である。
  • この役目は ARP ではなく、近隣探索(ND)と呼ばれる仕組みが引き継いでいる。
  • 近隣探索は独立した専用の仕組みではなく、ICMP の IPv6 版(ICMPv6)の一部として実現されている。一度調べた対応をしばらく覚えておく、ARP キャッシュに似た仕組みも持っている。
  • 第 7 章 7-2 で見た ARP は同じネットワーク全員に一斉に呼びかけるブロードキャストを使うが、近隣探索はマルチキャスト(宛先を絞ったグループ全員にだけ届く呼びかけ方)を使う。

しくみの話

同じネットワーク内の機械同士が通信するには、相手の MAC アドレスを知る必要がある。第 7 章 7-2 で見た ARP は、これを調べるための独立した専用の仕組みだった。新しい形式の IP アドレスでは、この役目を近隣探索(ND)と呼ばれる仕組みが引き継いでいる(#3)。近隣探索は ARP のような専用の仕組みではなく、第 6 章で見た ICMP の IPv6 版である ICMPv6 の一部として実現されている。呼びかけ方にも違いがあり、ARP は同じネットワークの全員に一斉に呼びかけるブロードキャストを使うが、近隣探索はマルチキャスト、つまり宛先を絞ったグループ全員にだけ届く呼びかけ方を使う(#4)。呼びかけられた機械のうち、その IP アドレスを持つ機械だけが返事をする点は ARP と同じである。また、一度調べた対応をしばらく覚えておく、ARP キャッシュに似た仕組みも近隣探索は持っている。
