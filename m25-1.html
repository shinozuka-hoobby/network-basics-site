第 25 章 VPC をつなぐ — ピアリング・ハブ・ハイブリッド　25-1

1 対 1 で直接つなぐ

このページでわかること

VPC 同士をつなぐ方法の 1 つに、2 つの VPC を直接つなぐやり方がある。直接つないだ相手の、そのまた相手までは自動では届かない。このページでは、この仕組みと、その制約を確認する。

このページの目次

かけあい

VPC が増えてきたので、2 つの VPC 同士をつなぎたいんですけど、どうすればいいんですか?

一番シンプルな方法は、2 つの VPC を 1 対 1 で直接つなぐことです。この仕組みをVPC ピアリングと呼びます。

ピアリングって、第 9 章で BGP の話をしたときにも聞いた気がします。

よく覚えていますね。第 9 章 9-2 で見た、AS 同士が経路の情報を交換し合うピアリングとは別の意味です。ここでは、VPC 同士をつなぐ接続のことを指します。

同じ言葉なのにややこしいですね。つないだら、それだけで通信できるようになるんですか?

もう 1 つ手順が要ります。第 24 章 24-2 で見たルートテーブルに、相手の VPC 宛ての経路を追加します。VPC ピアリング接続は、つながる土台を作るだけです。

土台を作って経路も足せば、どんな VPC 同士でもつなげるんですか?

1 つ条件があります。つなぐ 2 つの VPC で、IP アドレスの範囲が重なっていてはいけません。

範囲が重なってると、何がまずいんですか?

宛先が重なって、どちらの VPC への通信か区別できなくなるからです。重ならない範囲どうしでしか、VPC ピアリングでつなげません。

つなぐ相手の VPC は、同じ AWS アカウントの中にある必要があるんですか?

いいえ。別々のアカウントにある VPC 同士や、別々のリージョンにある VPC 同士でも、VPC ピアリングでつなげます。

分かりました。あと、VPC A と B をつないで、VPC A と C もつないだら、B から C にも通信できますか?

できません。VPC ピアリングは 1 対 1 のつながりで、つないだ相手を経由して、さらに別の VPC へ届けること(推移)はできません。

B と C の間で通信したいなら、どうするんですか?

B と C の間にも、直接 VPC ピアリング接続を作る必要があります。

そういえば、先輩が似た状況で困っていたって聞いたことがあります。VPC A-B、VPC A-C をそれぞれ VPC ピアリングでつないだのに、B から C へは通信できなかったそうです。

まさに今の話です。推移しないという性質を知らなかったので、直接の接続が無いことに気づかなかったんでしょう。

じゃあ、VPC の数がどんどん増えていったら、大変なことになりませんか?

良い質問です。VPC の数が増えるほど、必要な接続の組み合わせも増えていきます。次のページで、その問題と、別の解決策を見ていきましょう。

まとめ

  • VPC ピアリングは、2 つの VPC を 1 対 1 で直接つなぐ仕組みである。
  • 第 9 章 9-2 で見た、AS 同士が経路情報を交換するピアリングとは別の意味である。
  • 別々のアカウントや、別々のリージョンにある VPC 同士でも、VPC ピアリングでつなげる。
  • VPC ピアリング接続を作るだけでは不十分で、第 24 章 24-2 で見たルートテーブルに、相手の VPC 宛ての経路を追加する必要がある。
  • つなぐ 2 つの VPC は、IP アドレスの範囲が重なっていてはいけない。
  • VPC ピアリングは推移しない。VPC A-B、VPC A-C をつないでも、B-C 間は自動では通信できない。
  • B-C 間で通信したいなら、B と C の間にも直接 VPC ピアリング接続を作る必要がある。

しくみの話

VPC ピアリングは、2 つの VPC を 1 対 1 で直接つなぎ、互いのネットワークの範囲まで通信できるようにする仕組みである(#22)。ピアリング接続を作るだけでは、実際にどの通信をそこへ送るかは決まらず、第 24 章 24-2 で見たルートテーブルに、相手の VPC 宛ての経路を追加する必要がある。つなぐ 2 つの VPC は、IP アドレスの範囲が重なっていてはいけない(#26)。ピアリングは同じ AWS アカウントの中に限らず、別々のアカウント・別々のリージョンにある VPC 同士でも作れる(#26)。VPC ピアリングは点対点の接続で、推移しない。VPC A と B、VPC A と C をそれぞれピアリングでつないでも、B から C への通信を、A を経由して届けることはできない(#26)。B と C の間で通信したいなら、B と C の間にも直接ピアリング接続を作る必要がある。GCP の VPC Network Peering も、同じく推移しないことと、IP アドレスの範囲が重ならないことが必要な点は共通している(#30)。
